# 用场景记住英语词

creatoros-output: social-content-pack.image-carousel

让读者先看懂“发生了什么”，再记住这个词为什么用在这里。不要把释义旁边配一张无关的漂亮图。

先根据用户的词组、受众和范围核实含义与用法，优先查 Cambridge、Oxford Learner's Dictionaries、Merriam-Webster 等词典。区分常见义、词性、及物性和搭配；不为凑组硬塞生僻词。IPA 统一英式或美式，查证后再用，不根据拼写猜。保存来源链接，事实拿不准就省略或说明。

为每个词选一个日常场景，让人物的动作、视线、物品和关系直接体现词义。对易混词，场景必须让差异看得见；必要时加一个自然的短例句。一个词只讲本次对比最有价值的意思，不冒充完整词典。内容稿用方便推敲的文字即可，不需要固定 PageSpec 或 JSON 教案。

## 视觉表达

角色与视觉参考是本 Skill 的 `assets/reference.jpg`。先查看这张图，沿用其中主要男女角色的脸型、发型、发色和青年动漫比例，不另创一套人物；服装、动作与场景可随词义调整。保持暖色自然光、清晰表情、生活感和统一文字层级，人物服务语义，不能只换背景重复摆拍。参考图中的词组、释义、IPA 和标识不是必须照搬的内容。

每格以大而清楚的英文词为入口，核实后的 IPA 作辅助；底部必须有两行相互对应的解释：简短英文释义或例句在上，对应中文在下。英文词标题不算英文解释，不能只有中文释义。两行应表达同一个意思并与场景对应；关键差异可用红色点出。文字置于干净区域，避免复杂背景压住字。不要添加无关标语、水印或装饰碎字。

用户给六个词且未指定版式时，一张竖版 2×3 六格图是合适默认，不是六张图。词多或内容拥挤时再拆图，数量由可读性决定，用户明确的张数优先。整组读完应能解释各词的区别，而不只是记住画面。

## 制作与自检

先完成词义与场景设计，再用可用的原生生图工具制作实际图片。保持整套上下文，不要求每格或每页与前后完全独立。保留实际提交的完整 Prompt、内容稿和词典来源，按宿主要求交付文件；没有实际图片就不能声称完成。

生图时把本次调用的 Skill 目录下 `assets/reference.jpg` 解析成绝对路径，通过生图工具的参考图片参数实际传入；只在 Prompt 中写文件名，或只自己看过图片，都不等于给图像模型提供了参考。若文件缺失或工具不支持参考图，先报告限制，不静默改为随机人物。交付时记录实际传入的参考图片路径；`SKILL.md` 是说明文件，不是图片参考资产。

检查词与场景是否对应、每格是否具备英文解释及对应中文、角色是否与参考图一致，以及拼写、IPA、易混词差异和小屏可读性。客观记录发现的问题；不要为了追求完美擅自无限重画。若宿主没有生图能力，明确交付 Prompt 草案并说明未生成图片，不用占位图冒充。
