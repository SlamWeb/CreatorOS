# Agent 计划执行 SPEC

## 2026-11-03 续接通知的失败与安全重试

- 计划事件只在聊天收到完整结束回执后标为 done；请求 ID 已存在不代表处理成功。旧失败/中断请求缺少安全阶段证据时保持 unknown，不自动重放；已完成的历史事件不迁移、不重新通知。
- 宿主在模型请求前保存 prepared/model_started，在任何 stream/complete 输出交给 Agent 前先持久化 output_seen。首次零输出的连接/超时失败，或重启后有明确零输出证据的未完成尝试，可在同 event/request 下最多尝试3次；每次间隔至少30秒。收到任何输出或执行工具后失败为 unknown；确定错误及重试耗尽为 failed，均不冒充 done、不自动重放工具。
- 协议/阶段/次数/结果写现有会话 requests JSON；退避复用 AgentPlan.continuation_until，失败/未知沿用 continuation_state 字符串，无新 SQLite 字段或迁移。claim/release/fail/ack 均按事件版本与租约 token 核对，新事件清除旧租约/退避。重启不清重试预算，重复调度不新建请求或重复追加同一宿主通知。
- 零输出不证明远端没有处理模型请求，安全重试仍可能再次消耗模型 token；能证明的是没有将模型输出交给本地工具。已经产生本地副作用或无法证明阶段的旧请求不自动重试，真实生产和发布不作为恢复测试夹具。
- 受控复现首次10054后原实现把 done 当成功；本轮修复保留失败证据。新增10项与旧续接共13/13（28.8秒），此前计划/能力/契约/重规划/独立进程HTTP联合49/49（97.8秒），普通聊天/上下文联合27/27（39.2秒），各批次有交叠、均无跳过。验证首次连接失败、部分输出、真实 skip 后断线、重启安全/未知与旧失败、重试耗尽、线程未启动、租约/事件CAS及单通知/单请求去重。不调用真实模型，不恢复那条真实旧计划；未运行浏览器或全量 reliability。

## 2026-11-03 计划能力声明

- `creatoros.plan_capabilities` 是不初始化 Agent、工具注册表或 Web 的纯声明模块；同一份数据提供计划工具名、计划动作、自动续接直接调用动作、自动续接修改后续计划的动作，以及是否允许等待完成。模型 Schema 的工具枚举、计划服务校验、Web 续接工具集和工具执行守卫读取这些声明，不再各写一份清单。
- 三种调用场景分别授权，不取并集。例如素材集 create/export 可写进持久计划，但续接不能直接调用；Skill 库 add 可用于普通计划，续接修改后续计划只允许 get。未知工具、动作或场景默认拒绝，新增注册工具不会自动获得计划/续接权限。
- `request_review` 仍是宿主检查点，不注册为模型工具；只有 start_content_run 可等待完成。生产防重、精确 Revision/摘要观察、retry/skip、重启恢复、已提交步骤保护和账号归属仍使用原实现，不由动作声明推导。
- 工具名、模型 Schema、v2 请求摘要与步骤持久化格式保持；旧契约计划只读，不迁移或自动重放。账号工具总授权、宿主账号参数注入和资源归属校验仍为独立约束。本次没有新增工具、任意脚本执行或后台任务类型。
- 新增能力时先登记真实工具/参数及账号资源权限，再显式声明各场景动作；未声明的场景保持拒绝。新增异步类型仍需独立实现观察/恢复契约，不能只打开等待开关。
- 验证：新增能力矩阵、未知拒绝、真实隔离 HTTP 改计划、导入边界及模型 Schema 锁定 8 项，与既有计划契约/重规划/续接/账号宿主共 43 项联合通过（87.550 秒，受控 Provider/生产者，不调用真实模型或浏览器）。全部 53 个模型工具 Schema 的规范 JSON SHA256 与基线 `0e9c7e0` 相同；新增回归接入零付费 reliability allowlist。未运行全量 reliability 或部署服务。

## 2026-11-02 生产结果观察边界

- AgentPlan 不再直接读取 Run、Revision、ProductionTask、Topic 或 Series 的 ORM 对象；通过 `creatoros.runs.observation` 在当前事务中获取生产状态和准确版本凭据。计划仍负责自己的步骤、依赖和状态，生产观察不会启动或重试任务。
- 只观察生产状态时不会导入生产执行器和 Codex；生产错误定义在 `creatoros.runs.errors`，原有 `creatoros.runs` 和 `service` 导入仍指向同一异常类。
- 保留账号归属、等待无 Run 的任务、部分完成/失败的兄弟任务、版本摘要核对和已提交生产防重复；原 HTTP/工具契约与历史计划不变。
- 验证：独立 SQLite 的生产观察四项，以及计划、工具契约、重规划、防重复与续接共 33 项通过；其中生产者为受控测试替身，不代表真实模型质量。

## 2026-11-01 当前工具契约

- 新计划使用带 v2 标记的请求摘要；历史计划只读、历史步骤与结果不改，不在启动/调度/续接时自动重放。
- 创建时依据注册工具契约验证固定参数与引用结构，解析依赖后完整校验再执行；生产 action 与 kind 显式，Skill 统一用精确 skill_ids。重新规划和等待识别同步使用新动作。
- 新8项与原2项定向路径通过，包含真实HTTP任务提交、受控生产者完成、等待后精确收图；受控生产仅验证调度与状态，不冒充真实Codex图像效果。
- 现用计划、重规划及自动续接测试参数同步迁移，另选8项关键路径通过；历史参数投影仍原样保留，缺少brief的负例仍拒绝。独立暂存版本的31项联合检查及精确Skill重做1项通过；后者改用无音频夹具，避免与本改动无关的ffprobe环境依赖。

2026-10-28：创建计划时对不含依赖引用的工具参数预校验，避免计划已建却因固定参数格式错误无法开始；回执明确说明计划已创建不等于生产已提交。生产步骤仅在宿主记录了工具调用前参数校验失败时允许修正或重试，原参数及错误保留；已提交、状态未知或缺乏该证据的历史失败仍不可自动重提。依赖引用需要在运行时解析并校验。新代码不修改或自动重跑旧计划。

2026-10-28 制作粒度与旧历史纠正：独立理由图默认一图一制作任务，同题25图用25项tasks并行，生图到剪辑交给通用计划。账号请求仅在本问上下文尾部附当前执行契约，纠正旧助手关于音轨ID前置的错误；不改写历史消息。模型材料工具只列举/读取，旧import_link调用返回BGM直接传递路径；内部材料导入兼容原HTTP字段。现有正式25图单线程任务按用户选择保留运行，不重提、不自动拆分。

验证：隔离真实前端+DeepSeek，带有旧错误助手历史，模型未调import_link，提交25项单图任务及依赖收图的视频计划，分享全文保留。实际SQLite为25tasks/25runs/25queue/1collection/1plan；生产消费者held、0attempt，没有调用Codex或重复生成正式图片。证据在tmp/parallel-agent-live-20261028。首次脚本过早读取队列产生假失败，修复等待后观察同一请求通过；不是重新发送模型请求挑结果。

2026-10-28：通用 `request_review` 检查点等待指定依赖后持久化为暂停并唤醒当前会话，需显式 resume 后才继续；未选检查点的固定步骤不额外唤醒模型。已提交步骤及其失败、未知、部分成功记录不覆盖；并行生产批次等待所有任务终态并逐项保留结果，再触发判断。出现未知或尚在执行/失败的生产，拒绝通过改计划追加替代生产；新图片步骤不得与本计划已提交的同题同名图片重复。只允许确知无副作用的非生产失败步骤 skip，保留错误；未知和生产步骤不能 skip。暂停不取消已运行的任务。隔离 SQLite 测试涵盖检查点断点、通知去重、批次部分失败、未知生产防重复以及维护状态；受控本地测试不代表模型质量。

自动续接只允许同计划的读取和受控调整，不能另建计划或直接生产；修改省略的步骤由宿主保留，待执行视频可调整输入。无法连接模型时保留事件并退避，避免密集轮询。外部业务数据与宿主系统指令分开，续接失败记录仍可见。真实 DeepSeek + 隔离前端验证：检查点后修改后续步骤并完成；另通过注入隔离失败计划验证模型安全跳过失败只读步骤、修改依赖并继续查 BGM，全程无生图。注入失败测试不是由模型自行提交生产，受控批量故障测试亦不等于真实 Codex 故障验收。

2026-10-27：账号会话可提交通用持久计划，步骤只调用已注册且允许的账号工具；每一步记录结果、依赖和状态。独立步骤不受其他分支失败影响；下游等待成功的制作产物，完成或失败后由宿主通知原会话继续处理。原会话和账号校验、步骤提交身份及停止后的未知结果记录必须保留。

剪辑使用本计划产图时，创建只含精确 Run 的素材集，不使用会自动汇集历史的选题素材集；收集前检查版本和摘要，剪辑前校验集合版本。已有独立素材集仍可用于普通计划。后台运行的已成功步骤不自动重新生图；已提交失败的制作需回原任务核对，禁止盲目重试。暂停只阻止新步骤，不停止已经启动的任务。

验证：隔离 SQLite 和本机真实 HTTP 覆盖计划提交幂等、跨账号会话隔离、失败分支不阻塞其他分支、依赖失败阻断、通知领取与 ACK、重启后未知写操作不重提；额外检查历史素材混入场景。模型和 Codex 的完整真实端到端验证由总任务单独执行和记录。

真实前端初测：DeepSeek 创建了两张并行图片→精确收图→视频计划，Codex 实际生成两图。首次视频因独立素材集未被视频入口接受而失败，失败记录保留；Agent 随后自行绕路另建计划并做出视频，这暴露了失败续接权限过宽，不能算首轮通过。已修正独立素材集的账号归属检查，并将失败续接限制为只读工具，隔离回归覆盖；继续复用两图验证修正后的真实视频，不重新生图。计划活动及未处理通知纳入维护门禁。

复测：隔离服务加载修正后的代码，从真实前端让 DeepSeek 用首次计划的独立素材集创建视频计划；Codex 生成 MP4、任务进入待人工验收，计划自动完成并续接同一会话，两张原图没有重新生产。该复测只验证复用收图后的剪辑及续接，不宣称修正后从头生成图片到视频整条链路又重跑了一遍。真实 Codex 中断功能尚未实测。代码与前端构建尚未部署到正式服务。
