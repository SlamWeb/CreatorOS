# BGM 集

使用当前账号的音乐素材作为曲目索引。通过 `manage_material` 列出音频、查看分析状态或读取分析摘要；按选题、情绪、时长和音乐变化挑选合适曲目，并说明选择理由。已有分析优先复用。

新增音乐时，将用户提供的音频登记到当前账号素材库，再对该素材启动 `bgm-understanding` 分析。`analyze` 只表示后台已受理；用 `analysis_status` 查看结果，完成后用 `analysis` 读取摘要。分析结果、完整起音候选及来源随素材保存，不将本机路径当成跨账号可用的索引。

分析时间以实际分析片段为基准；使用前注意来源回执中的片段起点。节拍和起音为算法候选，未试听时不要声称已经确认卡点。如果分享链接无法取得音频，说明实际原因，不假装分析完成。
