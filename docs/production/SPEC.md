# 单视觉会话生产链路

## 目标与边界

解释真实点击生产链路、2026-10-01 交付失败及本轮逐页交付修复。架构图是解释资料，不是质量评审，也不证明新版完整生图已验收。

## 计划

- 记录 Web → ContentRun → Mind → Storyboard → Visual → 图片 → 回执校验 → SocialContentPack → 人工验收的职责。
- 图中区分原链路和本轮新增逐页 checkpoint；不虚构 image2.5 模型版本、百分比或自动发布。
- 用生成图片表达架构，检查顺序与箭头；保存图片及文字事实说明。

## 验收

- 链路箭头遵循编号顺序，不跳过内容交接；明确原始图片与网页产物不是同一目录。
- 事实与本轮限制可回溯到 integrations、runs 和 web 的 SPEC。

## 实际结果

- 内置 imagegen 生成初稿并两次局部校正箭头，最终保存 production-chain.png；未宣称选用了无法指定的 2.5 模型。
- 原链路故障、修复后交付/恢复和限制记录在 production-chain.md。图的绿栏标记为相对旧链路的本轮目标，避免与历史已实现能力混淆。
- 编号和主链路箭头逐一核对，无 2→4 / 3→5 / 4→7 捷径。原生生成文件未删除。
