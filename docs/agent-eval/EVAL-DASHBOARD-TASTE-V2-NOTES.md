- 桌面：左侧固定轮次，右侧依次呈现改动、结论、基准比较、各测试集和关注问题。每项测试显示自己的最近运行；首次失败和重跑次数保留可见。基础测试默认仅显示摘要行，详情收起，失败时突出。
- 手机：轮次切换置顶，其余内容依相同决策顺序纵向排列；保留共同题分母及不可比较原因。
- 蓝色用于操作、选中和开发中标识，绿色用于通过，红色用于失败，琥珀色用于待复核或未形成结论，灰色用于未运行或未知；文字同时标识状态，不依赖颜色。安全边界独立列出，未运行与待复核均不算通过。
- 基准默认展示同一开发线的上一轮；数据不足或条件不匹配时保持未知，不显示虚构涨跌。数值中的 Token 用量仅为示例。
- 这是用户认可方向的静态代表页面，未展示测试题详情、完整运行历史、空态、加载态、回滚流程或交互；这些以 [Harness 设计草案](EVAL-HARNESS-DESIGN-DRAFT.md) 的交互和验收要求补足。未实现任何产品功能。
