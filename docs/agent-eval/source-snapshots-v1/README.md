# 回归题源快照

本目录按规范化 JSON 的 SHA-256 保存题源；文件名即摘要。v1/v2 的三份题源及其工具专项授权题源，从与原目录摘要一致的文件独立复制，不改变原目录、题集、运行记录或其摘要。每次加载都验证来源路径、数据结构、身份和摘要；快照缺失或损坏时拒绝使用，不自动覆盖或重建。快照承载的是题目定义，不能替代历史模型运行证据。

新增目录版本时设置 `sources_frozen: true`，先完成来源与执行适配器审查，然后显式冻结来源：

```powershell
python -m creatoros.evaluation.regression_catalog --manifest docs/agent-eval/<新目录>/catalog.json --freeze-sources
```

命令核对目录及来源后原子创建不存在的摘要文件；已有文件必须校验通过，绝不覆盖。已封存的目录正常读取时必须有对应快照，不会回退共享源。之后检查新目录、旧目录与各自历史记录，再提交目录与快照。新题默认未准入；冻结来源不意味着可安全运行。使用 v3 适配器时，`adapter_source_sha256` 和 base 来源摘要必须匹配代码中独立发布的固定基准；v4/v5 的 `adapter_source_sha256_by_namespace` 分别绑定每个来源的固定摘要。题号还必须属于相应守卫版本和来源的授权集合，目录不能通过修改自身摘要授权变化后的题目。修改基准或已准入题应重新审查并发布新的守卫与授权版本。开发时单独修改共享题源，需为新版本更新摘要并冻结，不能篡改旧目录和旧快照。

历史展示核验固定摘要和目录结构，不使用当前运行时的评分版本校验；真正执行仍须通过对应守卫、运行时依赖、完整性和副作用检查。未来调整目录格式或守卫版本时，仍须保留旧版本读取及版本范围。
