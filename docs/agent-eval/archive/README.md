# Retired Eval evidence

These dated reports and metric snapshots describe the former account/workbench Eval. They are preserved historical evidence, not current specifications, executable instructions or current scores.

The old runner and task definitions have been retired. Historical commands here are not supported. Follow [the active B01-B50 benchmark](../benchmark-v2/README.md) for new runs. Original data/artifacts under `data/agent-eval*` were not moved, deleted or regraded.

The orphaned `tests.test_eval_coverage_v3` validator was removed after its retired input files had already been removed; its prior source remains in Git history. This does not remove the dated reports or change any historical result.
