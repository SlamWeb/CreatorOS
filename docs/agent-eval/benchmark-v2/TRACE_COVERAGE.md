# Trace 来源与扫描覆盖（2026-10-31）

这是起题前的本地只读快照审计，不是模型成绩。所有发现的可读Trace均纳入机器扫描；语义选题按根因聚类，没有宣称逐段人工读完。二进制图片、音频、数据库和ZIP只记录身份、大小与hash，未做OCR或音频理解。当前评测工作自身新生成的preflight文件不倒灌历史来源快照。

## Agent 会话

| 来源范围 | 文件数 | 字节数 | 解析与限制 |
| --- | ---: | ---: | --- |
| 正式Web会话根与CLI会话根 | 1,920 | 400,908,947 | 1,107个JSON/JSONL全部解析；701文本扫描；112二进制hash |

正式根是`data/creatoros-agent-sessions`与`sessions`。38个Web会话中有250条持久用户turn，另有3条宿主计划续接；CLI有12条旧式用户消息。242条Web用户turn有真实DeepSeek请求证据，另8条为受控或缺请求模型证据，不能把目录位置直接当自然用户身份。用户任务按`session_id + turn_id`去重；旧记录缺turn时保留原消息索引，不把请求快照重复携带的历史算新题。

741份请求快照中提取690个当次响应的工具调用。787个唯一finished请求包含778主请求、9摘要请求；32个缺usage，保持未知。累计输入与峰值、cache子集分开，不能把cache重复加进total，也不能把此遥测当供应商账单。一个真实turn存在相同参数`get_skill_extraction`连续27次的直接证据。

补充范围包含全部发现的1,262个非正式主Trace文件、关联侧文件，以及`data/agent-eval`和`data/agent-eval-workbench`全目录。9,312个文件分为eval 8,264、probe 862、test 186；这些来源不混入250条正式用户turn分母。补充文件有4,850个唯一内容hash；跨正式与补充来源共1,055组相同文件内容，其中18组跨origin。完全相同字节只分析一次，每份副本仍登记canonical路径。450个query内容hash聚类仅是诊断分组，不能当450个独立任务。

唯一坏JSON来自旧工作台的生产进度文件，保留hash、解析失败行列与原始文本扫描状态，没有修补历史记录。旧Eval错误包括故障注入、采集器与产品信号；嵌套快照、报告间重复的error字段只是出现次数，不能换算独立产品失败率。

## 原生生产、研究与Codex ledger

另一份只读普查覆盖`outputs`、`output`、`production-skills`以及会话、素材、导出、Skill安装/提炼/调研等正式根：登记20,114文件、扫描11,642个文本文件与89,047条JSONL记录，JSONL解析/读取错误均为0，扫描期间已登记文件变化0。该范围与Agent普查有重叠，不能相加冒充独立Trace数。不存在的讨论目录如实登记缺根，依赖目录和版本控制目录按规则排除。

从来源索引得到491个原生thread身份，在本机当前及归档Codex会话目录找到并扫描301个匹配ledger文件，25,231条记录、4,021,610,484字节，解析错误0。**190个来源thread没有找到原生ledger**；它们可能仍有仓库checkpoint、SDK Trace或回执，但不能因此补造完整原生会话，也不能宣称所有历史native ledger齐全。扫描完整覆盖的是当时可发现的文件，不是保证历史从未丢失。

## 起题与隐私边界

Agent候选按38个不同来源turn整理，包含一条明确标为宿主续接的组件候选。新50题按固定业务场景形成40开发/10保留题；family不跨split。真实意图规范化与安全/当前契约合成变体在每题`origin.type`中区分，来源文件用相对路径、hash和会话/turn身份定位。B50属于当前交付协议扩展，不声称历史已经出现过`submit-tool-v1`路径。参考轨迹约束不是唯一序列，也没有标为人工验收。

Agent正式与补充可读数据的边界修正凭证模式、显式敏感键检查均无非脱敏命中；这是启发式检查，不保证识别全部个人信息。最初的`sk-`子串匹配误中了Skill名，已加词边界后重扫，未把误报当泄露。公开仓库只保留本汇总和脱敏题目出处元数据；完整清单、原文侧数据与11MB补充inventory留在本地忽略目录，不提交用户原文或凭证。

本地索引为`tmp/benchmark-20261031/agent-census/{inventory,eval-inventory,summary,candidates}.json`以及`tmp/benchmark-20261031/codex-census/{summary,ledger-summary}.json`。冻结manifest可以只保存这些索引的hash；每题执行前验当前源码和静态前端，不重复扫描全部历史媒体。此阶段无模型调用、无正式业务写入、无服务重启，旧题集、分数、图片与失败记录保持。
