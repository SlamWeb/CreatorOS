## 自然用户表达

现有题集保留原始请求和夹具，作为可复现的受控回归，其中专业术语、明确禁止操作、极端对抗指令有测试价值，但不代表普通用户的表达频率。不能直接删去限制后沿用同一预期：是否可自动创建、生产或修改往往取决于授权范围。

后续新增独立版本及样本：保留目标和合理上下文，避免重复枚举禁止事项；明确区分用户未授权的副作用与用户明令禁止、产品默认安全边界及需要澄清的权限。应与原题作配对对照，但分别冻结和报告，不能同题号同分混算。示例是“把这三个词组分别加到英语辨析栏目”或“做两张借入、借出的图，完成后打包给我”；具体授权与生产状态必须依据产品契约核实。不能用简化表达自动放松账号隔离、批准/发布等权限。B50等协议注入题保留为专项，而非伪装成自然用户请求。

## 校准边界

部分规则依赖 Judge，没有人类标注一致性；AI编写或复核的样本不构成人工真值。视觉评分如无法绑定实际送评媒体与业务对象，将相关结论保留待复核。独立留出样本需避免在调整中反复查看结果；目前试验集规模有限，不可推广到50题。旧批按自己的标准展示，不自动改分。
