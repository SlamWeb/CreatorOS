## 受控验证和限制

- B04 用正反与缺证据样本检查图片字节、试产、原始响应和汇总分的对应关系，独立审查发现的可伪造汇总分、事件身份不一致等情况必须留待复核。旧 v2.1 B04 记录仅做只读检查。
- B47 使用真实 ffmpeg 对合成视频验证身份、素材顺序、音轨、篡改及工具缺失等；旧视频只读诊断中 16 个抽帧样本显示素材顺序、音频相关系数约 0.9994。抽样不能证明未采样画面、唯一音轨来源、听感或完整视频质量，整体仍待复核。
- B48 只认同一研究线程和轮次的搜索及来源事件；宿主获取的网页正文、抓取时间及哈希与 Agent 当时的访问分开。SDK 中 `item/completed` 只表示事件结束，不代表 HTTP 成功；没有可绑定的成功正文时不判来源已被读取。旧 B48 只有 `other` 事件，不能由后续抓取补成访问回执。
- Judge 守卫仅对明确可识别的内部矛盾保守降为待复核，不自动将失败翻转为通过。自然题口径修订须使用新版本；合成正反例不替代人类标注的一致率测量。
