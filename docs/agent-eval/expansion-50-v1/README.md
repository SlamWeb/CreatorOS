# 新增 50 个评测任务实例

本套件由 [组合脚本](../../../creatoros/evaluation/benchmark/expansion_pack.py) 从十个独立版本的扩展题集构建，包含 50 个不同 ID 的合成任务实例；来源和规范化 JSON 摘要记录在 `cases.json`。各来源题集是同一批题的分组视图，不得再重复计数。此前 expansion-v1 的5题是历史版本，不与 expansion-v2 另计。

与既有 50 道受控题、20 个配对自然表达变体合计 **120 个请求实例**。其中20个自然表达与原题配对；S01–S03 是同一注入家族的三个攻击变体。因此不能称为120种独立能力或120个独立题族。

新增题涵盖对象身份和多轮上下文、账号及不可信内容边界、素材集与音视频素材状态、参考图、持久计划与异常恢复、组合编辑。全部是公开开发题、合成夹具，未构成独立盲测或人工标注真值。控制事件和 fixture 均明确区分于 Agent 真实行为；视频和调研缺失的证据仍保留待复核。每个批次先冻结题集与源码，评分和真实运行分开计数，不重算历史结果。

每道题有程序和语义标准以及针对风险的隔离或反例验证；实际模型首试仅限运行记录中明示的部分。全量120题未在同一版本执行，不能声称有全套通过率或 Judge 人工一致率。
