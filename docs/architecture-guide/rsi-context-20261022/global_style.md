# Global Figure Style — CreatorOS context and Skill iteration

## Color Palette
- Primary (#FBEEDB): stable host instructions and frozen task inputs.
- Secondary (#EAF2ED): conversation, persisted state, accepted results.
- Accent (#D6662C): context boundaries, submission and feedback arrows.
- Blue (#EDF2FA): current Query, model inputs and production.
- Neutral (#262421): text and fine outlines.
- Background (#FFFEFB): solid warm white, no texture.

## Typography
- Language: Chinese, retaining Query / System Prompt / Skill / Codex / Judge.
- Title: informal handwritten Latin, clear Chinese sans-serif subtitle.
- Body: clean Chinese sans-serif, not handwritten small Chinese glyphs.
- Hierarchy: title 64px, section 42px, node 32px, annotation at least 25px at 3840px width.

## Shapes & Strokes
- Rounded rectangular nodes, near-black fine outlines, no raised cards.
- Stacked context regions with pastel fills and thin separator rules.
- Solid directional arrows for actual data flow; orange feedback arrow for the next round.
- Dotted outline only for an explicitly labelled current limitation, never an unimplemented path disguised as current.

## Visual Rules
- Match the user's PersonClone reference: restrained whiteboard map, broad whitespace, thin orange title rule.
- No shadows, gradients, 3D, decorative mascots or unrelated icons.
- Show separate chat and RSI context boundaries. Do not imply automatic shared memory.
- Short Chinese labels in the picture; complete wire text is supplied as a companion artifact.

## Technical Specs
- Target: 3840×2160 landscape, high-resolution readable educational infographic.
- Native generated bitmap via built-in image generation, not a screenshot of HTML.

## Negative Prompt
No dark background, gradients, shadows, neon, ornamental icons, extra arrows, illegible labels, pseudo-code wallpaper, invented RAG, invented long-term user memory, or claims that a file path proves the image was viewed.
