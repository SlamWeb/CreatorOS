# 任务收件箱（2026-10-20）

## Draft / 用户目标

提交生产、调研、Skill 提炼后，能从固定入口找回原任务；新草稿、入库 Skill 与栏目有本机未查看提示。已查看不等于批准、保存或发布。

## 最小接线与边界

- 顶栏任务按钮打开轻量任务列表：进行中、待处理、最近；点任务回原 Run、栏目调研或 Skill 草稿。失败保留且可找到，不自动重试。
- GET `/api/work-inbox?limit=50` 只读 SQL 与现有任务 JSON 元数据。不调用生产/修复/get 草稿扫描，不哈希所有 Skill 目录；不写正式任务状态。
- 当前 SQLite、文件元数据是业务真相；本机 `localStorage` 仅记首次基线和已查看版本。首次开启不把历史消息全点亮；旧待验收/失败仍列出。
- token 由任务状态、Revision、草稿 digest 等稳定值构成，不以 heartbeat 为版本。打开详情才清对应提示；打开任务列表本身不清除。
- 列表展开、页面可见时轮询；收起/隐藏停止。导航和重新聚焦进行一次刷新。请求失败保留原列表并显示刷新失败，不冒充完成。
- 保留现有主题、Logo、Agent 浮层及权限。入口不新增模型工具、自动生产、自动批准或任务中心状态机。

## 验收

1. Given 历史任务 When 首次启用 Then 仍可查找，不全显示未读。
2. Given 新任务/稳定版本变化 When 刷新 Then 任务/栏目或 Skill 出现提示；仅 heartbeat 更新不重新点亮。
3. Given 点开对应任务/对象 When 刷新浏览器 Then 已看状态保留，业务状态与文件哈希不变。
4. Given 失败或损坏元数据 When 读取 Then 失败记录保留，坏文件提示部分不可读，不触发恢复/生产。
5. Given 收起/后台标签页 When 等待 Then 停止定时请求；展开后刷新并保留原始跳转。
