# 相同 pending 回执的模型视图引用（2026-11-07）

历史 Skill 提取 Trace 的同一 job 多次返回完全相同的 `running` 回执。当前既有投影已去重若干长文本字段，但重投影固定旧快照后仍有重复，见 [逐请求报告](TRACE_REPLAY_2026-11-07.md)。针对这一种已定位的回执，本次在模型视图中对完全相同的后续结果使用指向此前可见结果的引用；保留当前 `id/status/operation/error/queue_state/next_action/digest/revision/cancel_requested/observation_warning` 等字段。引用只说返回内容一致，不声称本次执行了实时读取。原账本、工具调用、后台工作和权限校验不变。

条件：工具必须是 `get_skill_extraction`；成功 JSON 的 `job_id` 与返回 `id` 一致、状态 `queued/running`、无错误及 unknown 标记；调用参数、原始回执及现有投影结果完全相同；来源调用 ID 在本次请求中唯一且来源已出现；内容足够长且引用更短。任何条件不符则保留原投影。非该工具、完成或失败回执不进行此优化。引用只表明内容相等，不保证该次查询是实时的；原有 pending 延迟读取机制可能复用旧回执。

原始账本、历史工具结果和索引不修改。投影从当前可见消息的开头确定来源，因此一般追加新结果不会回改既有请求前缀；初次升级时历史投影改变会产生一次前缀变化，调用 ID 冲突、压缩、缺源或其他视图变化也可能导致回退和缓存变化，不能保证命中。
