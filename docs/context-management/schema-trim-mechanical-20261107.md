初次对照时这是隔离候选，没有改变生产代码；之后已将同样的变换接入账号工具的模型可见 Schema。原版来自 `2720cfa` 的账号工具快照；候选只在 Schema 节点递归执行三种变换，保留每项业务描述、工具名/顺序、字段名、required、枚举、长度、引用、约束和非空默认：

1. 删除 73 个 `default: null`：这是 JSON Schema 注解，但模型可见的默认提示减少。
2. 删除 27 个与所在 `$defs` 名称完全相同的 title 注解。
3. 将 8 个仅包含两个不同、其中一个为 `null` 且各支只有 `type` 的 `anyOf` 改为等价的 `type` 数组；不动包含其他关键字的联合。
