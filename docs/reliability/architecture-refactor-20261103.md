## 当前交付与范围

## 修复与边界

- 聊天视图写入失败按未开始或结果未知分别处理；执行后结果未知不能自动重放。一个会话的恢复存储故障不会阻止其他会话启动；独立后台任务仍按其原有授权运行。最后尚未持久化的聊天内容不保证找回。
- 图片库存 `received:only` 用于查询，不再因宿主暂时只观察到一张便自动选择。已接收图片由 Codex 明确选择并排列；旧已确认回执按原摘要重放。SDK 事件和工具请求异步，查询结果是当时已观察的库存，不证明后面没有图片；这也不能保证内容质量。
- 从头重做、普通生产和批量生产的首次授权，与用户明确恢复分开；首次授权的幂等和账号检查在数据库事务内执行，保留既有待核对队列与旧产物。已授权的固定后台步骤不会因聊天视图故障一概暂停。
- 同账号 BGM 可复用已有分析文件，但现有缓存未区分分析时间范围和版本；视频任务未自动带分析结果。完整 Skill 包上传、跨账号 BGM 共享和 Agent 受管图片脚本仍是后续需求，不因重构而宣称已实现。
- 显式恢复前先核对冻结归属，旧队列错误在重置前写入 `production_queue_history`；栏目转移会挂起未认领队列和等待中的阶段任务，阶段历史写入 `production_task_history`。正在执行的任务不会因转移被自动取消。

数据库回滚不能撤销真实模型调用、写入其他目录或平台发布；隔离测试使用独立临时根和端口，且未重跑旧任务。Codex 用户目录和外部账户并不会随 worktree 自动隔离。受控 producer、注入的 HTTP 响应和浏览器截图不能证明真实模型或视频剪辑成功。

## 扩展边界审查

当前是模块化单体，并非即插即用平台。Skill 完整 ZIP 上传、跨账号 BGM 授权复用、Agent 受管脚本都仍需新增明确的应用入口和契约。制作任务当前只覆盖图片、视频及有限的素材种类；音频分析缓存尚未按片段和分析器版本区分，视频任务不会自动携带该 JSON。Skill 来源、解包、资源权限和结果未知恢复仍须在实现这些新能力时设计。不要把未来的 DS 脚本执行等同于给模型开放 shell。

SQLite、文件系统和外部模型调用不构成统一事务；本机资源归属检查也不等于多用户身份认证。现有的进程内锁不应解释为跨机器互斥。
