# 从生图到视频

同一个选题可以有多项独立生图任务，再把图片收进素材集，交给剪辑 Skill 制作视频。每项任务有自己的制作记录和验收入口。

## 准备账号与 Skill

1. 在全局「Skill」页安装或准备 Skill。
2. 进入账号，打开「Skill 库」，从「已安装的 Skill」中选择，点击「加入账号库」。这里保存引用，不复制另一份 Skill 文件。
3. 新建栏目时填名称即可。进入「栏目设置」，从账号库中勾选栏目需要的 Skill，点击「保存栏目 Skill」。

每个制作任务从这个栏目的 Skill 中选择；一个任务可以选择多份及具体版本。旧栏目的绑定与历史任务仍保留兼容。

新任务不要求 Skill 声明图片或视频输出类型，按本次选择的 Skill 与任务要求交给 Codex；实际能否完成仍取决于 Skill 内容和素材。

## 在一个选题下拆分生图

进入栏目并添加选题，在该选题的操作菜单点击「拆分制作」。每项分别填写「名称」和「制作要求」。

- 每项在「选择 Skill」里勾选本栏目需要的 Skill；不同任务可以选择不同的组合。

点击「提交并开始制作」。每项独立执行，图片进入同一素材集；通过「查看任务」验收，通过「查看素材集」集中选片。任务会固定所选版本的正文、资源和摘要，之后编辑栏目默认或 Skill 不会改写已有任务。

## 选片并制作视频

在账号「素材」中打开对应的「素材文件夹」。可以调整顺序、勾选保留图片，用「连续预览」检查；「下载所选 ZIP」可单独导出图片。

点击「制作视频」，填写任务名称和剪辑要求，在「这一步使用的 Skill」中勾选栏目里的剪辑等 Skill。

BGM 可从「已保存音频或视频」选择，也可「上传 MP3、音频或视频」，或填写「BGM 分享链接」后点击「读取链接」。文件最多 64 MiB；链接必须实际解析取得文件才能使用，解析失败时请上传文件。视频文件需包含可用音轨。

「开始方式」有两种：

- **立即使用当前选片**：至少保留一张图片；提交时准备并固定当前选片和 BGM。
- **等待选定图片任务全部完成**：明确勾选当前选题的图片任务，再点「保存并等待图片完成」。后台等待这些任务完成后准备图片 ZIP 和视频制作，不需要一直开着页面。

等待只针对勾选的任务，不会猜测还要等账号里的其他图片。缺图或上游失败会显示「待核对」及原因，不会静默跳过；可在修复后「重试准备材料」，或「取消等待」。等待期间尚无视频 Run，重试准备不会重跑已经成功的图片任务。

## 查看结果与边界

视频任务会出现在同一选题的「制作任务」列表。进入「查看任务」后，可播放、下载 MP4、批准或「提出返工」。返工先保存要求，再显式开始生产；旧产物保留。视频详情不提供图片专用讨论和发布入口，批准也不等于发布。

草稿暂存在当前标签页；提交成功后可以离开。若提示提交结果待核对，使用「核对同一提交」或「核对同一视频提交」，不要另建一批重复任务。

这套流程用于明确的生图→选片→视频衔接，没有通用 DAG / 工作流画布。当前验证不能代表任意规模并发、长视频或任意外部链接都能成功；实际产出取决于 Skill、素材、Codex 环境及媒体工具。
