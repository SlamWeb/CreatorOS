## 已核对的实现与缺口

- `WorkspacePage.tsx` 已有账号树，但选中账号仍自动回退其第一个栏目；需将账号级浏览与栏目级浏览分开。
- `AgentPage.tsx` 已有持久化账号绑定和独立历史筛选，视觉布局仍复用总览；复用 ChatEntry / Session / SSE / request_id / version，不复制第二套模型调用。
- `TopicLibrary.tsx` 为宽列表与条目级小链接；取消上移/下移控件，不顺手删除既有 reorder 接口或 position 字段。
- TopicView / topic-library 尚无封面字段；RunSummary 已有校验过的 cover_url / card_count。实现时复用既有图片 URL 与校验逻辑，并在服务器批量投影，不能逐卡拉完整 Run。
- 当前有空账号删除与无生产记录的选题删除，没有栏目删除接口。现有产物、Run、Revision、Attempt、发布记录不可由视觉重构隐式删除。

## 交互契约

### 导航与账号聊天

- 点击账号名称显示本账号所有内容；点击栏目仅筛选该栏目。账号无栏目时显示创建栏目入口，不切到其他账号。
- 工作区切到“账号 Agent”后，标题显示固定账号身份；会话列表只属于该账号。总览留独立入口。
- 当前栏目可以是输入旁可移除的资源引用，不改变会话 creator_id，也不把栏目选择当成后端权限校验。
- 换栏目不改绑聊天；换账号切换对应会话。账号 A 草稿不能被送到 B；刷新/切换/历史选择零模型请求。进入未分配栏目时不得沿用上一个账号会话。
- 复用现有 `/agent?creator=...&chat=...` 深链语义，映射为同一工作区视图；不破坏旧深链和总览入口。URL 保存 creator/series/view/chat，筛选与返回位置独立于对话绑定。

### 内容卡片与详情

- 一张卡片对应一个选题；有图片时只以第一张为封面，不自动轮播。未生产仅文字，不生成假图或空图片框。
- 卡片显示标题、简短文案和一个主状态。待选不冒充正式 Topic；已批准不冒充已发布。生产预览必须标为制作中，不冒充最终验收文件。
- 内容区域是可键盘访问的主入口；菜单是独立按钮，不能嵌套在另一个按钮内。编辑与来源进入详情或菜单，不再每张卡片堆多个链接。
- 点击已生产卡片打开既有 RunInspector 能力；未生产和待选打开选题详情，不制造空 Run 来满足路由。
- 详情主区域为图片轮播与缩略图；旁边是内容 / 生产记录。每页内容稿与实际 Prompt 放证据区，历史版本沿用原只读/批准摘要校验。
- 返回保留账号、栏目、筛选、分页和浏览位置。刷新详情只查询，失败/中断显式恢复，未知提交结果先查已有任务，不自动重发。
- 浏览排序与执行顺序分离：本轮不改变入队顺序、幂等键和生产调度；待选仍走 Preview → 人工确认。

### 移动端与异步

- 窄屏将账号树收成可展开的“账号与栏目”选择区；内容保持可点击，详情图片与文案纵向排列，不横向压缩文字。
- 空态 / 加载 / 读取失败区分；读取失败不伪装成没有内容。首次无账号保留创建入口。
- 切换资源时取消/忽略旧读取结果，避免 A 的封面、选题或消息覆盖 B；关闭页面只关闭观察，不取消后台生产。
- 快捷 Enter 需保留 IME 保护，Shift+Enter 换行；详情返回恢复卡片焦点，菜单 Escape 关闭。状态色必须配文字。

## Given / When / Then 验收

1. A/B 各有栏目和会话：在 A 内容页切账号 Agent / 切栏目 / 刷新，仍绑定 A 且零提交；切 B 不展示 A 正文，不发送 A 草稿；错误深链阻止发送。
2. 一个待选、一个待生产、一个合法产物、一个失败项：每种卡片只有正确主状态；待选无生产按钮，无图无假封面；封面点开对应对象，不按数组索引串用。
3. 点击有图片的卡片、翻页、看生产记录、返回：图片/文案/版本对应同一 Run；原筛选/分页/位置保留；全程零生产、审批、发布请求。
4. API 503 / 图片 404 / 重连 / 旧请求晚到：错误可恢复，不伪装空库，不重复写入，不把坏图当成验收产物。
5. 1440×900、390×844、320px：长标题、菜单、输入、图片均不横向溢出；实际操作键盘和触屏等价入口；Skill 页原流程回归。

- CUA 实际点击通过：消息队列卡片 → 第 2/6 页 → 生产记录 → 返回；待选筛选 → 无图片详情 → 返回仍选中待选且只有一项。生产/入队按钮在原型中明确禁用，不制造真实 Run。
