# CreatorOS Studio Web SPEC

## Eval 工作台 · 本次设计

- 目标：在既有 Eval 入口按更新轮次查看正式运行、逐题结果与历史记录，用户可选择基准并核对证据。评测登记与执行由后端和开发端负责，页面只读。
- `/eval` 显示轮次工作台；旧 `?case=`、`?batch=` 深链接和历史记录入口继续打开原只读页面。轮次、基准、运行和题目选择写入 URL，刷新和返回后恢复。
- 默认基准仅采用已登记的 `parent_round_id`，不以相同分支或创建时间猜测前驱。若当前轮恰好一次运行且父轮有唯一同套件、同版本运行，自动选择这一对；存在多个候选或缺少前驱时请用户选择。手动指定的基准及运行保持 URL 优先，最终可比性由后端核对。
- 左栏列轮次；详情显示改动、版本、运行状态、各套件最近一次运行与未运行项目。比较元数据不足时仅并排记录并标明尚未核实，不计算涨跌。保留失败、待复核及原始证据入口，失败不伪装为通过。
- 各运行分别展示冻结的必要及建议检查；单个专项有结果不代表整套必要检查通过。比较页的 Agent 费用为有相同计价口径的配对题估算区间，缺失不按零计。题目详情优先显示经核验的实际用户请求，否则标明模板。
- Given 无轮次 When 打开页面 Then 显示空态及历史入口；Given 请求失败 Then 显示错误和重试；Given 多轮/多运行 When 切换与刷新 Then 选择和证据不串；Given 缺少评测或比较依据 Then 显示未知/未运行而非伪造结果。
- 桌面与手机按照用户认可的 Taste V2 布局，展示加载、失败、长文和窄屏；外观截图与真实交互独立验证。未实现真实回滚和发起评测的控件不显示。

### 回归集浏览（本次）

- 评测工作台增加“回归集”只读入口，浏览常规和完整套件的版本、正式成员、候选、每题依赖和执行准入；URL 保存套件选择，返回轮次时保留原选择。
- 定义数量、适配器准入和真实运行结果分别表述；本页不推断已运行或成绩，不提供虚假的编辑或执行按钮。套件数据来自服务端目录，加载、缺失、错误及空列表均可见。
- Given 目录可用 When 切换常规/完整集 Then 成员和候选分别显示；Given 某题未完成准入 When 查看 Then 显示待核查原因；Given 刷新、返回或窄屏 Then 原选择可恢复且没有横向溢出；Given 目录服务失败 Then 显示错误与重试，旧评测记录仍可访问。
- 当前实现使用 `/api/eval/v1/suites` 只读目录：正式成员、未归类候选及执行准入分开展示，支持题号或标题搜索；显示范围未完成提示。题集详情显示登记中明确绑定该题集的运行，可跳入轮次/运行详情查看冻结的题集版本与范围，不合并跨轮结果；没有关联运行、读取失败和运行状态未知分别呈现。受控与隔离真实后端浏览器回归 9/9（含原工作台 4 项）通过，1440×900 / 390×844 截图已核对；这些结果不表示执行真实模型。
- 运行中的计划题尚未写入结果时显示“暂无结果”，失联时显示“暂无结果/状态未知”，终态缺项显示“未记录/未确认”；只有登记结果显式为 not_run 才显示“未运行”，避免将整批延迟汇总误判为未执行。


## 2026-11-09 · 账号工作台交互细化

- 栏目及作品卡片以轻微上浮回应悬停；视图切换提供短暂过渡，实际作品图片不裁切。横向导航确保已选栏目可见。
- Given 鼠标悬停或键盘聚焦 Then 可识别可操作对象；Given 触屏或系统减少动态效果 Then 不依赖视差操作并关闭位移；Given 切换栏目、素材和作品 Then URL、数据归属与操作语义不变。

## 2026-11-09 · 以栏目为中心的账号工作台（本次切片）

- 账号头部保留切换、账号数据、可用 Skill 和既有 BGM 入口；栏目以真实作品缩略图和名称切换，账号无栏目时呈现创建入口。账号工作台默认进入有效栏目，不再提供近期作品导航。返回和旧链接不得改变账号归属或丢弃素材深链接。
- 当前栏目内分作品、素材；栏目 Skill 与历史作品使用版本分别保持原语义。新素材明确关联栏目，旧素材以可核实来源展示，跨栏目和未知归属可在待整理中访问，不迁移或改写历史数据。图片内容按原始比例显示完整，栏目缩略图允许裁切。
- Given 多账号栏目 When 切换账号、栏目和账号资源 Then 页面只呈现正确作用域，返回保留栏目；Given 无栏目或未分配栏目 Then 仍有创建或分配入口；Given 跨栏目、未归属和旧素材链接 Then 均可访问并保持数据原样；Given 手机视口、加载/错误与无图片 Then 导航和状态可用。
- 用户预览以 D 盘独立快照和素材副本为准，不连接正式写入或自动恢复生产；预览限制须明确说明。桌面与手机截图分别检查，行为通过独立 API 和浏览器测试。

## 2026-11-08 · 账号工作台与全局导航

- 全局侧栏只保留五个一级入口；账号切换、账号级资源和栏目切换位于工作台主画布。已用 Skill 历史版本和未分配栏目保持可访问；近期作品入口由 2026-11-09 栏目工作台取代。
- 普通封面按原图比例显示，避免强制比例产生灰边或裁剪。账号和栏目切换沿用现有 URL、归属验证、聊天上下文和业务操作；从全局页面返回时尝试恢复本会话中最近的账号与栏目。
- Given 两个账号及多个栏目 When 切换账号、栏目或全局页面并返回 Then 全局导航位置稳定且不会串用账号数据；Given 无账号、未分配栏目、失效链接或加载错误 Then 状态和可用导航清楚；Given 正方形、竖图和无封面作品 Then 图片不被裁剪且缺图状态可见；Given 手机宽度 Then 账号、栏目和全局入口均可操作。

## 2026-11-07 · Skill 库与分类

- 目标：以四个同时可见的分类池查找、查看、选择 Skill；待分类单独显示，条目默认只显示名称，点击可查看详情，保留搜索、拖拽和点击加入；桌面保留组合区，手机可展开。蓝色实心主按钮与中性描边次按钮遵循根 DESIGN.md。
- 全局本机工作台分类为内容创作、视觉表现、素材处理、规则约束；可多选，空标签显示为待分类。分类是独立的展示元数据，以 Skill family 为键，既不推断旧角色，也不修改 Skill 文件、版本和历史生产快照。搜索和分类在 URL 中；组合草稿沿用原有存储与请求语义。
- 分类池默认展示前五项；更多条目按池独立展开和收起，搜索仍覆盖全部 Skill，收起不影响已选组合。标题用小图标及低饱和颜色辨识，不展示分类数量；待分类遵循同样的渐进披露。
- 待分类 Skill 可拖入正式分类池并通过带 revision 的接口保存；成功回执后才移动显示，冲突或结果未知时保留期望分类并要求核对最新值，不自动重试。点击设置分类仍可作为键盘与触屏替代方式；已分类 Skill 不因拖拽被静默覆盖。
- 分类读取失败时显示重试且不把未知分类当成待分类；保存失败保留选择，冲突或结果未知先核对最新数据，再由用户决定是否保存。无 Agent 会话的本机全局 Web 才能访问分类元数据；此限制不是完整身份认证。
- 保留详情、键盘选择、拖拽、安装、提炼、编写、RSI 历史、直接创建栏目和融合草稿；组合请求在途时不可改变选择。旧直接组合的角色约束仍由原业务规则决定。
- Given 分类编辑 When 多选并保存后刷新 Then 分类和筛选结果保持；Given 分类数据不可读或保存冲突 Then 明确提示并保留用户草稿；Given 搜索或浏览多个分类池 Then 不清除组合选择，多分类项目的选择状态保持同步；Given 融合提交进行中 Then 点击和拖拽不可改变其输入；Given 桌面或手机视口 Then 主流程与必要状态可访问。

## 2026-11-07 · 作品优先的编辑工作台（栏目页首版）

用户已确认下方方向，栏目页首版已实现；验收页仍为后续提案。桌面选中有效栏目后合并全局与账号栏目导航，手机保留全局导航和可展开栏目导航；作品卡片增强标题、状态与封面层级，无封面保留明确占位。新增跳到正文入口，移除嵌套 main。未新增状态筛选或改变制作、审批业务。

**目标：** 面试屏幕分享及日常操作中，让人先识别当前账号与栏目、作品和状态，再找到下一步动作；以真实作品而非说明文字作为主要视觉内容。方向为「作品优先的编辑工作台」，在现有白色画布、石墨正文、蓝色主动作与 C 标基础上重新组织空间。

**入口与落点：** 工作台进入栏目 → 浏览或筛选选题及作品 → 打开作品验收 → 返回原栏目和浏览位置。选题有多个制作任务时仍先进入其任务详情，不能假装每张卡都有唯一 Run。全局 Skill 与账号 Skill 库保留各自作用域和入口。

导航提议将全局入口与当前账号/栏目放在可收起的同一导航区，减少固定宽度；具体折叠方式和入口排序待视觉验证。栏目卡片以封面、标题、状态与必要数量为主；无封面使用真实标题和状态，不伪造图片。验收页以当前产物为主，版本、状态及后端允许的动作始终明确；下载、素材及技术记录仍可发现。手机改为单列，导航按需打开，媒体与操作均不被悬浮元素遮挡。

栏目标题区按用户反馈仅显示栏目名称与可打开的 Skill 名称，不展示账号面包屑、Skill 标签和版本号；精确版本仍可在 Skill 详情查看。栏目使用内容集图标，不使用文件夹隐喻。

栏目页不为任务铃铛保留整条顶部栏；铃铛位于右上角，运营指令快捷键仍可使用。其他页面沿用原入口，待后续统一设计。
隔离浏览器定向 2/2：任务面板打开/关闭及焦点、Ctrl+K、桌面和手机导航、长标题及聊天抽屉布局；另在真实内容的本机预览查看桌面与 390px，并打开任务面板。

**业务与状态边界：** 候选入队和批量生产是不同操作；批准与发布、返工与从头重做、普通重试与技术恢复不能合并。历史版本只读；展示任务冻结的 Skill 版本，不能替换为当前栏目版本。图片、视频、部分产物、失败、等待和结果未知按真实状态呈现；结果未知不自动重发。保留既有 URL、返回、草稿、账号作用域及幂等语义。

**后续待设计：** 筛选的范围和实际可用性、验收动作的最终位置。此稿不是批准删除现有入口，也不是对新筛选能力的实现承诺。后续扩散需结合栏目页实际使用和验证结果。

**验收草案：** Given 有作品与无封面选题 When 浏览栏目 Then 标题、状态和真实产物可区分；Given 选题有多个制作任务 When 打开 Then 不跳错 Run；Given 待批准或历史版本 When 查看 Then 分别展示实际允许的操作和只读状态；Given 失败或结果未知 When 返回/刷新 Then 保留真实状态且不自动重提；Given 1440×900、聊天打开及 390×844 When 使用主路径 Then 内容、焦点和操作不被遮挡。行为与截图分别验证，使用隔离数据，复用已有产物，不触发付费生产或发布。

**本轮验证：** 隔离构建与类型检查通过；隔离浏览器账号导航及栏目设置 13/14 通过，开发模式下首项目录故障注入未出现预期错误，同用例在隔离生产构建中 1/1 通过，原因未证实。新增栏目导航/键盘/移动端测试 1/1；桌面和 390px 视口人工查看，手机卡片由双列改为单列。受控测试不调用真实模型。预览连接本机现有服务，不等于已部署到正式静态资源。
