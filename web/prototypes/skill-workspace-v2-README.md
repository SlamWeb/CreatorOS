# Skill 工作台概念实验 2

目的：比较素材展台、栏目创作台和跨栏目配置矩阵三种布局；所有 Skill、分类及栏目均是示意，状态只保存在当前页面内，不连接真实 API。

从仓库根目录运行 `python -m http.server 15175 --bind 127.0.0.1 --directory web/prototypes`，打开 `http://127.0.0.1:15175/skill-workspace-v2.html?variant=a`。底部可切换 A/B/C；搜索、筛选、点击添加和拖拽仅操作示例。

独立评审按 Vercel Web Interface Guidelines 检查；已调整切换快捷键作用域、托盘高度、矩阵键盘滚动、移除后的焦点及多标签重复展示说明。桌面实际检查方案切换、拖拽和矩阵点击；真实中文输入法和小视口/放大时焦点遮挡仍需验证。正式实现前需确定可编辑分类、账号作用域、版本、栏目池写入、冲突与未知结果恢复，不能把原型当作已接通业务。
